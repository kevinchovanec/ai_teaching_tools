# Workshops

Facilitation activities meant to be run live with a group — as opposed to the [topic folders](../) elsewhere in this repo, which are meant for individual, self-paced learning. Each workshop is a self-contained page (usually just one HTML file) with everything a facilitator needs built in: instructions, roles, timing, and the activity itself.

## Activities

- [**Tinker Group Cards**](tinker-groups/) — a small-group discussion activity for AI-adoption workshops. Groups roll for a stakeholder-concern "issue card" tied to a project they're building, work through it with assigned roles (timekeeper, recorder, stakeholder voice) and guided questions, then draw a complicating "twist card" partway through. See [tinker-groups/README.md](tinker-groups/README.md) for facilitation notes.
