# Tinker Group Cards

A small-group discussion activity for workshops on responsible AI adoption — originally written for Extension-style community/outreach programs, but adaptable to any setting where people are building AI-assisted projects and need to think through how those projects land on real stakeholders.

## How it works

Each small group is working on (or imagining) a project that uses AI. During the activity:

1. The group rolls for an **issue card** (12 total) — a short scenario describing a stakeholder who raises a legitimate concern about an AI-assisted project (privacy, job displacement, disclosure, data sovereignty, overreliance, and similar themes).
2. Using assigned roles — **timekeeper**, **recorder**, and **stakeholder voice** (the person who speaks as the person on the card) — the group works through six guided questions: whose project is most affected, what's legitimate about the concern, how the stakeholder would actually encounter it, what they'd say in response, what they'd change, and (if it doesn't apply) why not.
3. Partway through (the activity suggests the 12-minute mark), the group draws a **twist card** (4 total) that complicates the scenario — e.g. the concern goes public, or comes from a key relationship.

No setup beyond opening the page — it's a single self-contained HTML file with the card text, a die-roll/draw interaction, and a rules panel built in.

## Running it

Open [index.html](index.html) on a shared screen or have each group open it on their own device. The built-in "Roles and discussion questions" panel and card mechanics are meant to run the activity with minimal facilitator setup.
