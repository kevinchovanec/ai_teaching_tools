# Embeddings

Two ways into the same topic — how models represent meaning as vectors.

- [**embeddings.ipynb**](embeddings.ipynb) — a walkthrough notebook: word embeddings (GloVe), vector arithmetic (`king − man + woman ≈ queen`, capital cities, and a cautionary bias example), and document/sentence embeddings with a BERT-family model. Best if you want the explanation alongside runnable code.
- [**Embedding Explorer**](embedding-explorer/) — an interactive, browser-based tool covering the same ground hands-on: look up a word's vector, try your own analogies, compare similarity between words or paragraphs, and see a 2D map of embedding space. No setup required. See its own [README](embedding-explorer/README.md) for how it's built.

Use the notebook for the "why," and the explorer for hands-on play — they're meant to reinforce each other.
